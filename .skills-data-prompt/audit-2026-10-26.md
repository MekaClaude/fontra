## 2. Security findings (remaining)

1. **`webAPIHandler` accepts arbitrary JSON kwargs** (`src/fontra/core/server.py`). Only registered
   `apiFunctions` (path ops) are callable, but there is no size/shape validation. Mitigation present:
   aiohttp default request body limit (~1 MB) and auth gate. Recommendation: add an allow-list of
   expected keys per function and reject unknown keys.
2. **`fontra-coach` `KnowledgeLoader.load()` fetches an arbitrary `bundlePath`** with no content-type
   check and swallows errors. Risk is browser-scoped (SSRF limited), but recommend validating
   `response.ok` and `content-type: application/json`, and surfacing a visible "KB failed to load" state.
3. **`card-renderer.js` uses `innerHTML` with `DOMPurify`**. The custom `sanitize()` escapes first then
   applies markdown regexes; ensure the regexes cannot be bypassed by nested `*`. Current allow-list is
   narrow; acceptable but add a regression test with `<img onerror>` payloads.
4. **`scripts/bundler_build_hook.py` previously used `shell=True`** (fixed). Audit other build scripts
   (`fontra-pak/build-timestamped.py` uses `shell=use_shell`) for injection if `cmd` ever includes
   untrusted input — keep `shell=False` defaults.
5. **`instancer.py` guideline handling** — no diff vs upstream now; confirm no silent regression
   (report P4-7). No action taken.

## 3. Efficiency findings

1. **`glyph_analysis.py` stem detection** approximates curves by connecting on-curve points only,
   missing true extrema; O(samples × contours). Acceptable for editor use but consider caching per glyph.
2. **`design_guide.py` loads the whole knowledge JSON once** (global cache). Fine; thread-safety not
   a concern in single-process server.
3. **`composition.py` `get_glyph_metrics`** sets `x_height = max_y` (heuristic). Reuse
   `glyph_analysis`/font metrics instead of recomputing; reduces duplicated work.
4. **`fontra-coach` `AnalysisCache`** had no eviction (fixed with LRU cap 200).
5. **`curve-inspector.js` stubs** return fabricated data (P2). Hide behind feature flags until
   implemented to avoid wasted work and misleading UI.
